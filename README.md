# perlDateManipBdd

A starting point for behavior-driven development (BDD) around Perl date manipulation.

## Status

This project is in its initial setup stage. Source code, test scenarios, and
development instructions will be added as the project takes shape.

## Getting started

Clone the repository and enter the project directory:

```sh
git clone https://github.com/justanyone/perlDateManipBdd.git
cd perlDateManipBdd
```
